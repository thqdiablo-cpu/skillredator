# skillredator

Skill do Claude Code para escrever conteúdo de Instagram sobre **design gráfico** com voz
autêntica e sem clichê — para designers, clientes e curiosos de cultura visual.

- `.claude/skills/redator-design/SKILL.md` — persona, pilares, formatos (carrossel, legenda, reels), ganchos, CTAs e checklist.
- `.claude/skills/redator-design/references/proibidos.md` — clichês proibidos e substituições.
- `.claude/skills/redator-design/references/pautas.md` — 30 pautas prontas.

## Uso

Com o repositório aberto no Claude Code, peça algo como:

> Cria um carrossel para mandar pro cliente sobre por que "deixa a logo maior" nem sempre funciona.

ou invoque diretamente com `/redator-design`.
